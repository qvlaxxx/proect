4. Маршрути та бізнес-логіка API (src/routes/)

src/routes/__init__.py
Завдання: Порожній файл пакету маршрутів.
src/routes/users.py
Завдання: Реалізувати ендпоінти для управління користувачами з прямими запитами до БД усередині функцій.
Деталі:
GET /users/ — отримати список користувачів з пагінацією (skip, limit).
GET /users/{user_id} — отримати профіль конкретного користувача за ID (з обробкою 404 помилки).
POST /users/ — зареєструвати нового користувача з перевіркою на унікальність email та username.
PUT /users/{user_id} — оновити дані профілю користувача.
GET /users/{user_id}/skills — отримати список усіх навичок, якими володіє або цікавиться конкретний користувач.

src/routes/skills.py
Завдання: Реалізувати маршрути для роботи з навичками та алгоритмом пошуку збігів.

Деталі:
GET /skills/ — отримати список навичок з фільтрацією за категорією, прапорцями can_teach/want_learn, пошуком за назвою/описом та пагінацією.
GET /skills/{skill_id} — отримати детальну інформацію про навичку.
POST /skills/ — створити нову навичку та зв'язати її з користувачем.
PUT /skills/{skill_id} — оновити існуючу навичку.
DELETE /skills/{skill_id} — видалити навичку.
GET /skills/{skill_id}/matches/ — реалізувати логіку автоматичного пошуку потенційних партнерів для обміну (якщо користувач хоче навчитись — шукати того, хто може навчити, і навпаки, у тій самій категорії).

src/routes/exchanges.py
Завдання: Реалізувати життєвий цикл запитів на обмін знаннями.

Деталі:
GET /exchanges/ — отримати список обмінів з можливістю фільтрації за статусом або користувачем.
GET /exchanges/{exchange_id} — отримати деталі конкретного обміну.
POST /exchanges/ — створити новий запит на обмін (з перевіркою, щоб користувач не створював обмін сам із собою).
PUT /exchanges/{exchange_id} — оновити статус обміну (прийняти/відхилити може лише отримувач; скасувати — учасники обміну).
Додати додаткові маршрути для зручності: отримання надісланих (/my/sent) та отриманих (/my/received) запитів.

src/routes/reviews.py
Завдання: Реалізувати систему оцінювання та відгуків після навчання.

Деталі:
GET /reviews/ — отримати список усіх відгуків.
GET /reviews/{review_id} — отримати конкретний відгук за ID.
POST /reviews/ — залишити відгук (з перевіркою, чи завершено обмін зі статусом completed, чи був користувач учасником обміну, і чи немає дублікатів відгуків).
GET /reviews/user/{user_id} — отримати всі відгуки, залишені про конкретного користувача.
GET /reviews/user/{user_id}/rating — розрахувати та повернути середній рейтинг користувача на основі всіх його відгуків.
